# 画面モック（見た目の参考・仮）

- `*.dc.html` は、画面の見た目の参考です（390×844）。そのまま動かすものではありません。
- 寸法・色・文字サイズは、各ファイルのインラインstyleが正解です。`docs/DESIGN.md` に要点をまとめています。
- 画面の内容（記事・ソース名・件数）はダミーまたはサンプルです。
- 対応:
  - Main / News2 / News3 … おすすめのニュースカード
  - Sources / Tools / ToolsGPT / ToolsGemini … ソース別・ツール別のフィード
  - Manage / ManageTools … 設定 > 情報源（ソース選択・ツール選択）
  - Settings … 設定　Explore … 探索（後回し可）　Saved … 保存済み

- 広告・スポンサー・有料・比較など、今回作らない画面は `design/mock_later/` に入れています。
