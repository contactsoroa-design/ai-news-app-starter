# 週次KPI（計測SDKなし）

**更新:** 2026-10-28  
方針: クリック計測SDK・ATT対象のトラッキングは入れない。App Store Connect と運用メモで足りる範囲だけ見る。

## 北星（フェーズ1目安）

| KPI | 目安 | 取得元 |
|-----|------|--------|
| D1 継続 | 40%+ | App Store Connect → 指標／保持 |
| D7 継続 | 20%+ | 同上 |
| MAU | 3,000 → 10,000 | Connect のアクティブデバイス等 |
| クラッシュフリー | 高いこと | Connect / Xcode Organizer |

## 収益・枠（B2B / アフィリ）

| KPI | 目安 | 取得元 |
|-----|------|--------|
| スポンサード表示感 | フィードで N 件に1（現行設定） | 仕様どおり。SDKカウントしない |
| アフィリ成果 | 週次件数・売上 | A8 / Impact / 直契約ダッシュボード |
| B2Bパイプライン | 送付数・商談・受注 | `docs/スポンサー候補リスト.md` の表 |
| 月商（税込/税別は社内で統一） | 加速パスの表に照合 | 請求・振込 |

スポンサー向け概算インプレッションは、**Connect のセッション×カード閲覧の仮説**でよい（過大申告しない）。公開後に実数へ更新。

## プロダクト学習（Plus候補）

| KPI | 取得元 |
|-----|--------|
| 要望メール件数 | `support@soroa-studio.com`（件名 `[Fast News AI] Feedback`） |
| Top10要望 | 週次でタグ: `無料で直す` / `Plus候補` / `対象外` |

## 毎週のルーチン（15〜30分）

1. Connect で継続・クラッシュを見る
2. アフィリ管理画面の成果を控える
3. スポンサー表を1行でも更新
4. 要望をタグ付け（Plus実装は急がない）
5. 異常（審査・規約・苦情）があればスポンサードを止める

## やらないこと

- 広告頻度を上げて「インプレッション」を水増しする
- 計測SDKを入れて数字だけ精密にする（方針・ASCと衝突）
- メールウェイトリスト人数をスポンサー成果の代わりに見せる
