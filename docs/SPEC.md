# 仕様（MVP・仮）

## 目的
AIニュースだけを、1枚ずつ縦スワイプで一目で読めるアプリ。情報源とツールを自分で選べる。「毎日開きたくなるか」を確かめる最小の形を作る。

## 仮定（決まっていないことはこれに従う）
- A1: ログインなし・外部DBなし。ユーザーの選択・保存・非表示（興味なし）はすべて端末内ストレージ（AsyncStorage）で管理し、外部サーバーに送信しない。
- A2: 表示・要約は **日本語＋英語**。収集時に日英ネイティブ要約を同時生成する。韓国語・スペイン語などは需要が出るまで作らない。端末側の機械翻訳は使わない。
- A3: 要約に使うモデルは `SUMMARY_MODEL`（環境変数）で切り替える。比較検証しやすいようモデル名は差し替え可能にする。
- A4: 最初のソースは `data/sources.seed.json` の公式ブログ系。RSSの有無は実装時に確認し、無いものは無効のままにする。
- A5: 見た目の確認用に、`data/seed_articles.json` から生成した `data/articles.json` のサンプル記事を使える。本番配信時も静的JSON（`EXPO_PUBLIC_FEED_URL`）を取得する形とする。
- A6: 下タブは「ホーム / 探索 / 保存済み / 設定」。探索はグリッド＋簡易キーワード絞り込み。
- A7: 自前スポンサード枠（AdMobなし）。`data/sponsored.json` の有効案件を、おすすめフィードにおおよそ8枚に1枚差し込む（先頭直後は出さない）。カードは記事と同型で、必ず「広告」ラベルと公式／アフィリURLへのCTAを付ける。表示のON/OFFは不可（常時表示）。個人データの外部送信・クリック計測SDKは使わない。

## 画面
1. **フィード（ホーム）**: 上部タブ「おすすめ / ソース別 / ツール別」。ソース別・ツール別は、チップ列と右端の「＋ 編集」（設定 > 情報源へ）。1枚ずつ縦スワイプ。おすすめ／探索は「ジャンル × ツール × 情報源」の掛け算（AND）で絞り込む。おすすめタブでは有効なスポンサードを稀に差し込む。
2. **カードの中身（上から）**: OGP画像 → 情報源の行（アイコン・ソース名・日付・ツール／ジャンル・件数）→ 見出し → 要約。右下に縦並びで、保存・共有・元記事・興味なし。画面長押しで元記事を開く。
3. **スポンサードカード**: 記事と同型。広告バッジ・広告主名・見出し・短文・CTA。興味なしボタンは出さない。保存は出さない。
4. **設定 > 情報源**: ソースのオン・オフ、ジャンルとツールの選択。選択数を設定のトップに表示。表示言語は ja / en。スポンサー枠の表示切替は置かない。
5. **保存済み**: 保存した記事の一覧。
6. **探索**: 絞り込み後の記事をグリッド表示。簡易キーワード検索可（スポンサードは探索に出さない）。

## 収集・要約
1. GitHub Actions の定期実行で、有効なソースのRSS等を取得する（Mac／端末に依存しない）。
2. URLとタイトルの類似で重複を除く。
3. 記事ページから og:image のURLを取得する（画像は保存しない）。
4. モデルに見出しと冒頭を渡し、JSONで返させる:
   - `title_ja`（おおよそ50〜70字、固有名詞と数字を入れる）
   - `summary_ja`（150〜200字前後、事実・仕組み・ビルダー向け結論）
   - `title_en`（14〜24語）
   - `summary_en`（95〜140語、日本語と同密度のネイティブ英語）
   - `tool_tags` / `genre_tags`
5. 要約は記事ごとに1回だけ作り、`data/articles.json`（`translations.ja` / `translations.en`）に保存して全ユーザーで共有する。品質ゲート（`npm run quality:check`）で英語の薄さを弾く。
6. 1日の件数（`MAX_ARTICLES_PER_DAY`、デフォルト **240**、**Asia/Tokyo** 日付）と月の費用（`MAX_MONTHLY_COST_JPY`）に上限を設け、超えたら止める。収集は **GitHub Actions のみ**（Mac不要）。UTC **:05 / :25 / :45**、1実行は `MAX_ARTICLES_PER_RUN`（既定 **5**）＋記事間隔 `INGEST_ARTICLE_DELAY_MS` で分割し、429時は待機再試行する。
7. 品質失敗時の再試行は最大数回。レート制限（429）は指数バックオフで再試行する。
8. フィードは直近30日を保持（件数制限なしのスライディング。ツール別最低件数の保護あり）。
9. アプリへの配信は `EXPO_PUBLIC_FEED_URL` 経由が本番想定（**GitHub raw 優先**。jsDelivr はキャッシュ遅れしやすいので主経路にしない）。開発中は未設定でも `public/articles.json` を都度取得。

ツール: `src/theme/tokens.ts` の `tools`（Claude, ChatGPT, Gemini, Cursor など）
ジャンル: `src/theme/tokens.ts` の `genres`（アップデート, 個人開発・収益化, マーケ・集客・ASO, SNS・ショート動画, 課金・ペイウォール, コスト・API料金, 開発, ビジネス, 画像生成, 動画, 音声, 研究, セキュリティ）

## 完了の条件
- 新しい記事が自動で取り込まれ、日英の見出しと要約が付く。
- 人が見て、事実の間違いが目立たない。
- スワイプで読め、保存・興味なし・元記事が動く。
- 情報源・ジャンル・ツールを選ぶと、おすすめ／探索の表示が変わる。
- 月の費用が上限を超えない。
