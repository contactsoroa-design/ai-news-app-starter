# ソフトローンチ手順（ウェイトリスト閉門なし）

**方針:** App Store 審査通過後はすぐ一般公開する。アプリ本体をウェイトリストで閉じない。有料必須は出さない（無料＋自前スポンサード「広告」）。

関連: `docs/提出準備-手元TODO.md` / `docs/ストア提出チェックリスト.md` / 月収300万戦略プラン

## 公開形態

| 項目 | 決定 |
|------|------|
| ウェイトリスト閉門 | **しない** |
| ローンチ時の課金 | **なし**（Plus は後段） |
| 広告 | 自前スポンサードのみ。「広告」表示必須。AdMob 等は入れない |
| LP メール登録 | **任意の告知用のみ**（ゲートにしない） |
| TestFlight | 品質確認の短期間のみ。本公開の代替にしない |

## 提出〜公開の流れ

1. `docs/提出準備-手元TODO.md` の Connect メタ・スクショを完了する
2. production ビルド → TestFlight で自分確認（スモーク3点）
3. Connect で「審査へ提出」
4. **Approved になったら即リリース（手動リリース待ちにしない／待つ場合は当日中に公開）**
5. 公開日に LP・X 等へ一斉告知（任意メールリストがあれば同時）

## 公開直後（加速パス）

- ASO・告知で獲得開始（無料＋広告）
- 数字が小さくても B2B「創刊スポンサー」打診を開始（メディアキット: https://soroa-studio.com/ainews/media-kit.html ）
- 高単価アフィリのみ `data/sponsored.json` に載せる（`docs/アフィリエイト運用ルール.md`）
- 設定の要望メールで Plus 候補を溜める（課金実装は急がない）
