# アフィリエイト運用ルール（高単価のみ）

**更新:** 2026-10-28  
実装の置き場: `data/sponsored.json` / `public/sponsored.json`（アプリは同型カード＋「広告」表示）

## 原則

1. **AdMob 等の第三者広告ネットワークは使わない**
2. **A8 ウィジェット／バナーSDKは埋め込まない**（追跡URLを自前カードの `url` に書くだけ）
3. **必ず「広告」バッジ**（`src/lib/config.ts` の sponsored.badge）
4. **低単価・量産はしない**（スワイプ体験を汚し、月商にも寄与しにくい）
5. クリック計測SDKはアプリに入れない。成果はアフィリ管理画面・スポンサー報告で見る

## 採用条件（すべて満たす）

| 条件 | 目安 |
|------|------|
| カテゴリ | AI / 開発者ツール / クリエイター向けSaaS |
| 単価 | 成果あたり **目安3,000円以上**、または継続課金の高い料率。下回る案件は原則見送り |
| 掲載形態 | アプリ内スポンサードカード可（プログラム規約でアプリNGなら見送り） |
| 素材 | 公式アセットのみ（自作ロゴ模写禁止）。出典は `assets/sponsors/SOURCE.txt` に追記 |
| 表示 | 日英タイトル／要約、CTA、`advertiser_name`、`active: true` |
| 審査 | A8/Impact 等で提携承認済みのリンクのみ |

## 追加手順

1. プログラム審査・承認
2. 追跡URLを取得（直契約URL優先）
3. `data/sponsored.json` に1件追加 → `public/sponsored.json` も同期（下書きは `active: false`）
4. 画像を `assets/sponsors/` へ。SOURCE.txt に出典
5. 実機で「広告」表示・外部ブラウザ遷移を確認
6. main に反映（CDN/raw が更新される）

## 却下・削除の基準

- 成果が極端に低い／ユーザー苦情
- 「広告」なし・誇大表現
- 全文転載や規約グレー誘導
- 地域制限で日本ユーザーに成果が付かない（主柱にしない）
