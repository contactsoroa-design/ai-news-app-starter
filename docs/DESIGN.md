# デザイン（仮・確定ではない）

画面は 390×844 を基準にする。ダークテーマ。日本語フォントは Noto Sans JP。値は `src/theme/tokens.ts` に置く。

## 配色（ツールごとに切り替え。記事の `tool_tags[0]`、無ければ neutral）
| テーマ | accent | background | panel | line |
|---|---|---|---|---|
| neutral | #B6F24A | #0E1117 | #1B2230 | #2E3748 |
| claude | #D97757 | #17110E | #2A1D17 | #3A2A21 |
| gpt（ChatGPT/OpenAI） | #10A37F | #0B1512 | #12251F | #1E3A31 |
| gemini | #4285F4 | #0B1020 | #131B33 | #22305A |

文字: 本文 #F2F3F5 / 補足 #A9B0BC / 要約 #B8BEC9。accent上の文字は background の色。

## カード（上から。座標はモック基準）
```
上部タブ        top 54  / 15px bold / 選択中は accent の下線2px
チップ列        top 100 / 高さ44 / 右端に「＋ 編集」固定（ソース別・ツール別のみ）
サムネ(OGP)     left/right 20 / 高さ160 / 角丸18 / top 104（チップ列あり: 152）
情報源の行      サムネの下16px / アイコン38 / ソース名 15px bold / 日付・ツール・件数 12px
見出し          20px / 行間1.42 / 太さ700 / 50〜70字で3〜4行（英語表示時は14〜24語相当）
要約            16px / 行間1.62 / 太さ500 / 日本語150〜200字前後・英語95〜140語（1画面に収まる密度）
右下ボタン列    right 10 / bottom 100 / 縦並び gap14 / 各52px・アイコン30・ラベル11px
下タブ          高さ84 / ホーム 探索 保存済み 設定
```
- 文字ブロックは left 20、right 80（ボタン列と重ねない）。サムネと文字は重ねない。
- 画像が無い・読み込めない時は、画像ありの時と同じサムネ領域（高さ160）を維持し、panel色の地にツールのブランドカラー・ジャンルピル・ウォーターマークを重ねたテーマバナーを表示して、カード間で目線の高さがぶれないようにする。
- チップ: 高さ44 / 角丸999 / 14px bold。選択中=accent地、未選択=line色の枠。

## 動き
- 縦スワイプで1枚ずつ（ページング）。
- 長押し（約0.5秒）で元記事をアプリ内ブラウザで開く。
- 「保存」は切り替え。「興味なし」は非表示にして次へ。

## 状態
- 読み込み中: カード形のスケルトン。
- 空: 「条件に合うニュースがありません。情報源を編集してください」と、設定へのボタン。
- 通信失敗: 再読み込みボタン。

## アクセシビリティ
- タップ領域は44px以上。アイコンだけのボタンにはラベルを付ける。
- 文字のコントラストは十分に。色だけで状態を表さない（選択中はチェックや太さも変える）。
