## 詳しい説明 — 日本語

```
情報収集しなきゃいけない
わかっているけど時間がない…
情報量が多いからとりあえず要点だけ掴みたい…

新時代を生き抜くAIビジネスパーソンにとって、情報は命です。
しかし、現代社会は情報の大洪水が発生しており、自分が欲しい情報を探すのにも一苦労。

最新のAI動向・ツール・セキュリティなど、AIを活用するうえで有益な情報だけを、スワイプで終えるように集約しました。

・探索グリッドとキーワード絞り込み
・情報源・ジャンル・AIツールの掛け算フィルタ
```

## 連絡先／ポリシー宣言メモ（審査・Data safety）

- ログインなしで主要機能が使える
- 記事全文は保存・表示しない（要約・出典・リンク・OGPのみ）
- ユーザー設定・保存は端末内のみ。個人データをサーバーに送らない
- 第三者広告ネットワーク・トラッキング SDK なし
- 自前スポンサードカードは「広告」表示あり・クリック計測の外部送信なし
- 金融・医療の助言アプリではない
