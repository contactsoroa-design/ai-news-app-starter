# 要望インボックス運用（Plus候補タグ）

**更新:** 2026-10-28  
入口: アプリ設定「ご要望・不具合を送る」→ mailto（`feedbackMailto`）。件名 `[Fast News AI] Feedback`。

計測SDKなし。メールを週次で仕分けるだけ。

## タグ

| タグ | 意味 | 次アクション |
|------|------|--------------|
| `bug` | 不具合 | 無料で直す優先 |
| `free-fix` | コア体験の改善 | 無料ロードマップ |
| `plus-candidate` | 追加価値として有料化できそう | Phase 4 の候補リストへ |
| `other` | 対象外・確認待ち | 必要なら返信 |

## 週次（KPIルーチンと同時）

1. 受信箱で件名 `[Fast News AI] Feedback` を集める
2. 本文の「種別」行を確認（なければ内容から推定）
3. 同じ要望が繰り返されたら `docs/週次KPI.md` の Top10 に記入
4. **コア（読む・基本保存・ソース）は有料に移さない**
5. Plus 実装は開始条件（繰り返し要望 / B2Bが乗った後）を満たしてから

## テンプレ（返信例）

ご意見ありがとうございます。スワイプでニュースを読む体験は引き続き無料です。追加機能のご要望はバックログに入れ、優先度を見て検討します。
