# App Store スクショ参照（Cal AI 風）

**用途:** 提出用フレームの正本。  
**元ネタ:** `store/screenshots/reference/`（ユーザー提供の Cal AI ストア／カルーセル画面）。

## Cal AI から借りる型（やる）

1. **ほぼ全面の角丸ダークカード**  
   外側は黒。内側にわずかに明るいチャコールの大きな角丸パネル。
2. **1枚1メッセージ**  
   上部に巨大な短い見出しのみ。説明文・ライムの下線・余計なバッジは置かない。
3. **端末が主役**  
   見出し下に大きめの端末モック。厚めベゼル・影・後ろのソフトグロー。
4. **ステータスはダミー**  
   実機の時刻・4G・電池％・緑インジケータは出さない（`9:41`＋簡略アイコン）。
5. **カルーセル前提**  
   枚ごとに違うベネフィット（ホーム／探索／絞り込み）。

## やらない

- ランキング・ログイン・Push・課金など未実装の合成
- Expo Go の青い歯車・開発用バナー
- 誇大表現・架空の星／DL数
- ヘルス／減量アプリの文言の流用

## 再生成

```bash
python3 store/screenshots/compose-store-shots.py
```
